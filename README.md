# TouchMedia Website Clone 🎬✨

نسخة كاملة وعالية الأداء مطابقة لموقع **[TouchMedia](https://touchmediaint.vercel.app/)** بكافة صفحاته وتأثيراته البصرية والفيزيائية ومميزاته التفاعلية.

---

## 🚀 التقنيات المستخدمة (Tech Stack)

- **React 18** + **Vite**
- **Tailwind CSS** (نظام ألوان داكن فاخر Navy & Gold)
- **GSAP & ScrollTrigger** (الحركات الاحترافية والتحكم في التمرير)
- **Lenis** (Smooth Scroll فائق السلاسة)
- **Framer Motion** (حركات العناصر والـ Modals)
- **Leaflet & OpenStreetMap** (خريطة تفاعلية بالوضع الليلي مع موقع المقر بالقاهرة)
- **Lucide React** (أيقونات فيكتور متجاوبة)
- **Zod & Web3Forms** (التحقق من البيانات ونموذج الاتصال المباشر)
- **Supabase Integration** (إدارة البيانات ولوحة التحكم CMS)

---

## 📂 الصفحات والمميزات المشمولة

1. **الصفحة الرئيسية (`/`)**:
   - **Preloader**: شاشة تحميل ذهبية مع شعار متوهج وشريط تقدم متزامن.
   - **Navbar**: شريط علوي زجاجي بتأثير Backdrop Blur وروابط Smooth Scroll وقائمة جوال منبثقة.
   - **Hero Section**: فيديو عرض ترويجي متسلسل (Nivea, CeraVe, Henkel)، كتابة آلية (Typewriter) للعنوان، ومؤشر ماوس مغناطيسي تفاعلي.
   - **Concepts**: شارة ثلاثية الأبعاد متحركة، نصوص متموجة، وكروت المفاهيم مع Spotlight يتبع الماوس.
   - **Marquee Logos**: شريط شعارات الماركات العالمية بحركة لا نهائية وانعكاس الاتجاه.
   - **About & Capabilities**: كروت 3D تفاعلية Tilt Cards، تبديل فوري لخلفيات القدرات الإنتاجية، وعدادات أرقام تفاعلية.
   - **Services Grid**: شبكة الخدمات الست مع زوايا ذهبية مضيئة وتوجيه لصفحات التفاصيل.
   - **Portfolio**: عجلة ثلاثية الأبعاد 3D Wheel ومشغل فيديو سينمائي متزامن على الديسكتوب + شبكة فيديوهات ذاتية التشغيل على الجوال + Lightbox Video Player.
   - **Our Clients**: سحابة تفاعلية بفيزياء مغناطيسية تطفو فيها شعارات العملاء وتتجاوب مع اللمس وحركة المؤشر.
   - **Contact**: نموذج إرسال مع تحقق فوري، بيانات المقر، وخريطة Leaflet داكنة.
   - **Footer & BackToTop**: تذييل كامل بالروابط وروابط السوشيال وزر الصعود للأعلى.

2. **صفحة تفاصيل الخدمة (`/services/:id`)**:
   - بانر سينمائي لكل خدمة (Events, Activations, Giveaways, In-Store, Road show, Beach booth).
   - بيان الرؤية (Manifesto) بخط Serif فخم.
   - معرض أفقي متجاوب (Horizontal Scrolling Showcase).
   - أكورديون مراحل التنفيذ (How We Execute).
   - زر بدء المشروع التفاعلي مع نافذة Modal مخصصة.

3. **الصفحات القانونية (`/privacy-policy` & `/terms-of-service`)**:
   - سياسة الخصوصية متوافقة مع قانون حماية البيانات المصري رقم 151 لسنة 2020.
   - شروط الاستخدام والخدمات التعاقدية.

4. **لوحة التحكم والمصادقة (`/dashboard/login` & `/dashboard`)**:
   - صفحة تسجيل دخول إدارية.
   - لوحة تحكم CMS لإدارة المحتوى (الخدمات، البورتفوليو، العملاء، الإحصائيات، الروابط، وبيانات التواصل).

5. **صفحة الخطأ 404 (`NotFound`)**.

## 💻 طريقة التشغيل (How to Run)

### 1. تشغيل خادم التطوير المحلي:
```bash
npm run dev
```

### 2. بناء المشروع للإنتاج:
```bash
npm run build
```

### 3. معاينة النسخة المبنية:
```bash
npm run preview
```
